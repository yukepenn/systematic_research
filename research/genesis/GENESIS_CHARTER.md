## Epistemic rules

1. **Nothing in the repository is an axiom.** Every recorded statement enters as one of:
   RAW FACT / REPRODUCED FACT / CURRENT IMPLEMENTATION / HISTORICAL RESULT / HYPOTHESIS /
   INTERPRETATION / GOVERNANCE RULE / RETRACTED CLAIM / UNKNOWN. Files named CURRENT_TRUTH,
   BASELINE, CLOSED, FINAL etc. are **claims to verify**, not authority.
2. **History is preserved while being questioned.** No historical run output is rewritten. All
   reboot artifacts live in `research/genesis/` and `runs/GENESIS_*`.
3. **A prior failure binds only at its exact tested scope.** Revisiting a family requires a
   genuinely different first-principles hypothesis, recorded as such. Parameter-neighbour retries
   are prohibited.
4. **First principles ≠ amnesia.** Known bug classes, timestamp semantics, and falsified exact
   formulations remain binding evidence.
5. **Every evaluated object is logged** in the GENESIS search ledger (immutable ID, data hash,
   family, params, ranges, cost model, result, parent). No invisible trials. Discovery is free;
   the winner's search debt is not deniable.
6. **Three evidence layers:** DISCOVERY (broad, consumed data, low claim ceiling) →
   DEVELOPMENT CONFIRMATION (frozen candidate, chronological, no post-result adjustment) →
   STRONGER EVIDENCE (legitimately untouched history, else prospective). Re-splitting searched
   data never manufactures OOS.
7. **Dependence unit matches the strategy** (session-clustered default for intraday). Chronology
   is non-negotiable. Multiplicity is tracked as a first-class quantity.
8. **Engineering certification before belief** for any high-value candidate: future-corruption
   negative control · causal positive control · source-timestamp emission · independent
   implementation · action parity · P&L identity · positive tests of guards. Two-sided tests.
9. **Spectacular results are presumed to be engineering defects** until certified.
   Simple robust profitable effects are not penalized for being boring.
10. **Protected data are scientific capital.** Spending a blind pool / the seal requires a written
    EVI case and is irreversible. $0 financial cost can still be scientifically expensive.
