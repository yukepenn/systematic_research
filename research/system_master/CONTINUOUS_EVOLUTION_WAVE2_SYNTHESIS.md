## What this wave established

1. **The session/hold-continuation construction axis is now exhausted at three independent
   attempts** (U3's binary overnight-flatten, U1B's graded ETH-threshold delta on both products,
   U4B's signal-gated giveback exit) — all three found the underlying diagnostic signal (U1's
   RTH>ETH continuation value, U4's giveback-decay predictiveness) to be real, but every actual
   construction destroyed more aggregate value than it protected. This is not a coincidence of
   weak mechanism choice; three structurally different mechanisms (hard flatten, graded
   threshold shift, signal-gated exit) all failed the same way, which is itself informative:
   the underlying continuation-value signal appears to be a *population-average* tendency
   without a clean actionable trigger, not a rule waiting to be found.
2. **The organization/entropy axis is exhausted at two independent attempts** (U8's level
   features, U8B's transition/rate-of-change features) — both genuinely new, non-redundant
   information classes, both real and chronologically stable in their strongest cells, both
   failing the mandatory right-tail check more decisively than any prior feature this campaign
   has tested (U8B's strongest cell would exclude the single largest winning trade in the
   dataset). U8B did confirm one qualitative mechanism from the owner's addendum (transition
   effects amplify with incumbent conviction) — a genuine scientific finding, just not an
   actionable one.
3. **U6B is the closest call in this campaign's history** — a real, safety-clean, non-2026-stub
   effect that simply lacks magnitude. This is a *different* failure mode than everything else
   this wave (not unsafe, not confounded, not redundant — just small), and is the one candidate
   worth revisiting if a mechanism with more surface area (more of Product A's scale-ups
   involving genuinely multi-contract gaps, not single-contract floor-hits) is ever found.
4. **U9/U9B open, rather than close, a genuine frontier.** This is the first time in the
   campaign's history real order-flow data has been tested at all. The result (no detectable
   signal) is an honest small-sample null, not a rejection — 62-232 events across 33-37 sessions
   cannot distinguish a true small-to-moderate effect from noise. This is explicitly a
   **re-testable-later** result: U9's frozen prequential design stays valid, and the honest next
   step is accumulating more scalping_lab sessions before re-running the same preregistered test,
   not searching for a different feature combination on today's data.
5. **SHADOW01 (new family, owner-generated hypothesis) closed cleanly** — a real but
   uneconomically small serial-dependence signal in shadow-setup outcomes, correctly identified
   and closed per its own preregistered criterion rather than forced into a streak-filter.

features redundant/closed; short-history data cannot support honest validation; no compatible
unused data remains; literature scout yields nothing; self-generated hypotheses exhausted) —
**this bar is NOT met.** Two genuine avenues remain open:

- **U9B's microstructure test should be re-run as more tick/BBO history accumulates** — not
  closed, deferred to a data-accumulation timeline outside this session's control.
- **A literature/mechanism scout (directive sec69) has not yet been performed** — local,
  OHLCV-derived residual-information avenues are now heavily explored (R4, R5, U5, U8, U8B all
  independently found real-but-unsafe or real-but-tiny effects), which is itself evidence that
  the *class* of locally-derivable information is close to fully harvested at this campaign's
  current sophistication — the next genuinely new mechanism idea is more likely to come from
  external literature on intraday futures microstructure, session structure, or trend-persistence
  research than from another transformation of existing OHLCV features (directive sec70's own
  standing preference).
- **Cross-market conditioning** (addendum sec45) remains available but requires a specific
  motivating mechanism before testing — none has emerged yet from this wave's own findings.
