## 2. The objective

Build the best defensible NQ system discoverable — not polish the current Solar object to a
local optimum. Simultaneous preferences, in the owner's order:

1. higher true per-contract production 2. higher risk-adjusted return 3. lower drawdown /
worst-week / left-tail damage 4. weekly and daily consistency 5. robustness across years and
regimes 6. genuine model diversification 7. implementable in NT8 without look-ahead
8. causal behaviour that survives rolling forward.

**No arbitrary return ceiling and no capture-rate target.** If a valid mechanism produces much
more, pursue it.

**Exposure-neutral units first**, always: points/session, points/trade, return per unit of
worst week, return per unit of DD/CVaR — then dollars at *disclosed* sizing. Contract count is
a deployment choice, never evidence of alpha. Never improve a research result by adding
contracts.

*"Make money every day"* is a measurable target, not a promise: positive-day rate,
positive-week rate, median day/week, longest losing streak, P&L concentration, worst week,
CVaR.

## 3. Do not force a single "best" object — keep a PARETO FRONTIER

At minimum maintain: **PRODUCTION** (max pts/session at tolerable tail) · **RISK-EFFICIENT**
(max production ÷ |worst week|, CVaR efficiency) · **CONSISTENCY** (max positive-week/day rate
without killing expectancy) · **LOW-EXPOSURE** (best under ≤1 NQ-equivalent average/peak) ·
**PORTFOLIO** (best combination of genuinely differentiated sleeves).

Sharpe alone does not decide — it penalises upside variance too.

## 4. Evidence vocabulary (mandatory in every report)

Never write *proven / unique / permanent / all / only / solved / the mechanism is* unless the
exact artifact supports that quantifier. Tag claims:
`FACT` · `REPRODUCED` · `SUPPORTED` · `WEAK` · `INFERENCE` · `UNKNOWN` · `FALSIFIED`.

Arithmetic resemblance is not mechanism identification. A fit is not a replication. A
four-window holdout is not global out-of-sample.

## 7. Attribution is part of the deliverable

For every promoted mechanism: what event creates expectancy, in which regimes, long or short,
which 5 % of trades carry the P&L, what precedes winners vs losers, whether the feature
forecasts direction / size / duration / failure probability, whether the gain is independent
information or disguised leverage, and what market behaviour economically explains it.
*A strategy whose P&L cannot be decomposed is not finished research.*
