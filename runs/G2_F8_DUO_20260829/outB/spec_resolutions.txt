R03 THE CONTROL ("the MC-51-frozen RV-only throttle"). MC-51's frozen expanding-decile

R04 MATCHED MEAN EXPOSURE. Implemented as timing components (VOLSIZE01 R08/R10
    machinery): timing(X) = logW(X) - logW(constant e_bar(X)) on the same scored subset,
    the constant control charged its initial entry only. Leg-vs-control statistic
    DELTA = timing(leg) - timing(rv_ctrl); mean-exposure differences cancel inside each

    card's comparison (a) vs constant exposure; DELTA is comparison (b).

R05 LEGS RUN (card observables + skeptic tightenings). All states are known at the close
    of s from data settled by 17:00 ET of s and apply to r(s->s+1); on-state exposure
    0.5, off-state 1.0.
    L1 TURBULENCE (FROZEN PRIMARY): wide matrix of panel ret_usd by date x root (all
       roots in the filtered panel; ret_usd scaling is immaterial — Mahalanobis is
       scale-invariant). Valid panel day = >= 18 roots non-NaN. At day d: asset set =
       roots non-NaN at d with >= 55 non-NaN among the 60 previous valid panel days;
       window rows = those 60 days restricted to rows complete on the asset set
       (>= 40 required, else state undefined); mu = window mean, S = window covariance
       + ridge 1e-8*mean(diag(S))*I; turb(d) = (r_d-mu)' S^-1 (r_d-mu) / n_assets
       (Kritzman-Li normalization). State on iff turb(d) > expanding 0.90-quantile of
       turb strictly before d (>= 252 prior obs).
    L2 HMM: 2-state Gaussian HMM on x = log(RV(s)) (log transform: a Gaussian family on
       a positive, heavily right-skewed variable; monotone, frozen pre-result, does not
       favor PASS). Sessions with >= 200 bars and RV > 0 form the input series. Refit
       calendar FROZEN (skeptic (c)): refit at the first session of each calendar month
       using ONLY observations strictly before it, min 504 prior obs; EM frozen: init
       means/vars from the below/above-median halves, A = [[0.97,0.03],[0.03,0.97]],
       pi = [0.5,0.5], 200 iterations, tol 1e-8; event state = larger mean. Filtered
       (causal, forward-only) P(event at s) under the params frozen at s's month refit.
       State on iff P(event) > 0.7 (card threshold).
    L3 COMPOSITE: z-composite {VXN close, RV21, corr60} where corr60(d) = Pearson corr
       of panel NQ ret_usd vs panel ZN ret_usd over the 60 most recent valid common
       panel days ending at d (>= 50 valid pairs; ZN frozen as the bond-futures leg —
       the canonical 10y note). Each ingredient z-scored by its expanding mean/std
       strictly before s (>= 252 prior obs); composite = equal-weight mean of the three
       z. State on iff composite > expanding 2/3-quantile strictly before s (>= 252
       prior obs) — top tercile throttled. This leg CARRIES the stock-bond-correlation
       modern-evidence caveat (printed beside its result).
    L4 10M-MA: monthly close = close of the last session of each completed calendar
       month; MA = mean of the last 10 completed monthly closes (>= 10 required). State
       on iff close(s) < MA.
    NOT RUN — CORR-SIGN LEG: demoted by the skeptic to the confirmation-only shelf (its
       episode is inside the 2019+ reserve); the demotion + caveat are printed.
    NOT RUN — BEX INDEX / FRED MACRO GATE: owner-gated acquisitions (skeptic (d));
