## 2. The novelty gate — every candidate must pass before it is EVI-scored

| | |
|---|---|
| **N1 RAW NOVELTY** | contains information **not deterministically reconstructible** from fields the project already owns |
| **N2 CAUSAL OBSERVABILITY** | observable **at the claimed decision time** |
| **N3 SEMANTIC CERTIFIABILITY** | timestamps, revisions and publication semantics can be **verified** |
| **N4 EXECUTION RELEVANCE** | could reasonably affect a tradable **NQ** decision |
| **N5 EVIDENCE PATH** | can eventually receive **stronger evidence** than another discovery-consumed historical fit |

**Failing N1 ⇒ classified `TRANSFORMATION OF EXISTING INFORMATION`, not information acquisition.**

> ### ⚠️ **"INDICATOR" ≠ "NEW INFORMATION".**
> A vendor product is **not** a new source because its code is proprietary, its name is impressive,
> or its vendor calls it institutional. **If it is ultimately derived only from OHLC / Last / BBO /
> volume / VWAP / moving averages, it is a TRANSFORMATION.** Every such product must be **mapped to
> its underlying observable fields** before it can count as acquisition.
> **FEATURE NAME ≠ OBSERVED FIELD.**

> ### ⚠️ **RAW OBSERVABLE vs INFERRED LATENT.**
> **Observable:** option price · strike · expiry · open interest · bid/ask · displayed depth ·
> trade print · timestamp.
> **Inferred:** *"dealer gamma"* · *"dealer positioning"* · *"smart money"* · *"institutional
> accumulation"* · *"support wall"*.
> An inferred quantity carries **model risk that vendor branding does not remove.** Any such product
> must document its observable inputs, its dealer-sign assumption, its 0DTE treatment, its
> open-interest timing, and whether positions are **estimated or observed**.

## 3. EVI scoring — ordinal, transparent, no fake precision

```
EVI ~ mechanism_prior x information_novelty x causal_quality x evidence_upgrade_potential
      x portfolio_independence x coverage_relevance x execution_feasibility
      / financial_cost / engineering_cost / calendar_cost / semantic_risk / irreversibility
```

Scores are **`LOW` / `MEDIUM` / `HIGH`** with stated definitions. ⛔ **No 0.873-style precision
unless derived.** ⛔ **No future return enters any factor.**

**`coverage_relevance` earns extra weight** if a family plausibly distinguishes trend vs chop,
continuation vs reversal, crowded vs uncrowded, liquidity stress, volatility regime, cross-market
agreement, or event-driven vs endogenous movement — **without loosening `P1`.** That is a
**structural prior**, not evidence of alpha.

⚠️ **`portfolio_independence` is necessary, not sufficient: `uncorrelated + unprofitable = ballast`**
— this repo has already bought that lesson with TSMOM.
