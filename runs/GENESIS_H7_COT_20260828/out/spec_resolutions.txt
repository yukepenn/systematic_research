R5  TRAILING 156-REPORT CAUSAL PERCENTILE. Window = the most recent 156 REPORTS
    INCLUDING the current one (reports i-155..i of the chosen series inside the R2
    window); pct(i) = #{window values <= value(i)} / 156, in (0, 1]; ties counted
    by <=. The first 155 reports are warmup and emit no state. (The alternative
    reading - 156 PRIOR reports excluding current - differs by one report of warmup
    and was NOT chosen; fixed here before computation.) "Report" is the literal
    window unit, so windows spanning the 203-day 2009-2010 reporting gap use the
    last 156 AVAILABLE reports; no calendar interpolation is invented (R15 merged).

R6  TERCILES. Fixed cuts on the percentile: T1 pct <= 1/3; T2 1/3 < pct <= 2/3;
    T3 pct > 2/3. NOT empirical terciles of the realized percentile distribution.

R7  PUBLICATION DATE. The Friday of the as-of date's ISO week
    (report_date + (4 - weekday) days), publication instant 15:30 ET, per the
    frozen causal_availability_binding and the vendor cadence quoted in
    DATA_CONTRACT.md par.4 ("published each Friday at 3:30 pm ET, using the data
    from the immediately preceding Tuesday of that week"). The holiday-shifted
    as-of dates (Mon/Wed; 14 in the full 209742 set) use the SAME Friday-of-week
    rule - the binding carves out no exception. Residual caveat: in rare holiday
    weeks actual publication can slip past Friday; a NON-GATE diagnostic excluding
    the shifted-as-of weeks is printed in diagnostics.txt to bound the exposure.

R8  CONDITIONED WEEK / TARGET. Conditioned week = the ISO week (isocalendar on
    session label) immediately FOLLOWING the publication ISO week. Target return =
    100 * (last-session close of conditioned week / last-session close of
    publication week - 1). "Friday close" = the last session close of the ISO week
    (Thursday on Good-Friday weeks; ~13:00 ET early close on post-Thanksgiving
    Fridays). In both irregular cases publication (Friday 15:30 ET) still precedes
    ALL post-entry price formation, because the market is closed from that week's
    last close until the next Sunday 18:00 ET open - so no look-ahead is possible
    at the entry close. The spec's "week starting the NEXT Monday 18:00 ET session"
    is read as WEEK IDENTIFICATION (the conditioned week's first session is
    Monday-labeled; per research_sdk/session_boundary.py that session OPENS Sunday
    18:00 ET), not as an intra-week entry time - the frozen target clause ("Friday
    close to Friday close") governs the measured quantity. Any earlier alignment
    (conditioning the publication week itself) is the look-ahead the spec forbids.

R9  WEEKLY GRID / SPLICE. Session closes built exactly as the certified H2 sibling
    (GENESIS_H2_CALENDAR src/h2_driver.py): deep substrate nq1m_2005_202605.parquet
    provides session labels 2006-01-01..2021-12-31 ("time" parsed as string);
    modern nq_1m_2022_2026.parquet provides 2022-01-01..2026-07-31; last END-stamped
    bar per session (hour >= 18 rolls the label forward); Saturday/Sunday-labeled
    artifact sessions dropped; every chunk passes seal_guard.truncate_presealed and
    the final frame passes assert_presealed. Weekly close = last session close per
    ISO week (isocalendar year+week of the session label). Weekly returns are
    computed WITHIN each substrate only, so the return spanning the 2022 substrate
    boundary (2021-W52 -> 2022-W01) is NaN and DROPPED (the back-adjustment regimes
    differ), as is the first deep week's undefined return.

R11 C1 STATISTIC. "Weekly clustered t" = two-sample Welch t between conditioned
    weekly returns of T3 vs T1 weeks (each non-overlapping week is one cluster;
    same reading the certified H2 sibling used for session-clustered). PASS iff
    (mean T3 - mean T1) < 0 AND t <= -2.0.

R12 C2 NULL. research_sdk.null_guard with unit = one week-row: decision_fn reads
    the tercile of the (circularly shifted) state frame - the tercile is a function
    of COT data only, never of returns, so shifting the finished label is free of
    the recompute-leak class; statistic = |mean(T3) - mean(T1)| scored against the
    ORIGINAL return alignment. verify_null_sensitivity with probe shifts [1, 7,
    101] runs FIRST (spec: "sensitivity first"). Full null uses ALL m-1 distinct
    shifts (m = usable weeks, m-1 >= 300 asserted). q95 via np.quantile(...,
    method="higher") - conservative, H2 precedent. PASS iff real |T3-T1| > q95.
