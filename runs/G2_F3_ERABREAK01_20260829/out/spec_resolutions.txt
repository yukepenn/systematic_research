R1. Eras and substrates.
    Era A (pre-0DTE): sessions 2016-01-01 .. 2019-12-31, from the deep parquet

R2. Session unit / bar stamping. session_id per session_boundary convention:
    18:00 ET open -> 17:00 ET close, END-stamped bars, hour>=18 rolls to next
    calendar day's label. RTH bucket = end-stamp minute-of-day in 09:31..16:00
    (390 buckets; the bar stamped 09:31 covers 09:30-09:31; the bar stamped 16:00
    covers 15:59-16:00). Last-30-minute window = end-stamps 15:31..16:00 (30 buckets,
    covering 15:30-16:00 wall-clock).

R3. 1-min log return. r_t = ln(close_t) - ln(close_prev) where prev is the
    immediately preceding bar in the SAME session and the stamp gap is EXACTLY 60s
    (a return spanning a gap is not a "1-min log return" -> dropped, counted, printed).
    Bars stamped 09:30 are loaded solely to supply the prior close for the 09:31
    bucket (the 09:30-stamped close IS the price at the RTH open instant); the 09:30
    bucket itself is not part of the profile.

R4. Per-session normalization. p_{s,m} = r_{s,m}^2 / sum_m r_{s,m}^2 over the
    session's PRESENT RTH buckets ("normalized to session total" = RTH session total,
    since the profile is defined on RTH). Missing buckets are absent (NaN), not zero.

R5. Session completeness filter (decided before computing): a session enters an era
    only if it has >= 370 of 390 valid 1-min returns AND a strictly positive RTH RV
    total. This removes early-close half-days (~210 buckets) without tuning; the
    excluded count per era is printed before verdicts. No other filtering.

R6. Era profile. P_e(m) = nan-aware mean over era sessions of p_{s,m} (count-weighted
    bucket mean). Era last-30 share = sum_{m in last30} P_e(m) / sum_{all m} P_e(m)
    (renormalized so incomplete buckets cannot distort the share).

R7. Break statistic. Spec: "profile L1 distance + share difference" = ONE primary
    scalar S = L1 + |dShare|, where L1 = sum_m |P_A(m) - P_B(m)| and
    dShare = share_B - share_A (both unitless fractions, summable). Component
    statistics L1 and |dShare| are ALSO evaluated against the SAME shared null as
    non-binding diagnostics. The binding p95 gate is on S only.

R8. Null. Circular shift of ERA LABELS over the pooled chronologically-ordered
    session axis (n_A era-A sessions then n_B era-B sessions, N total). All N-1
    non-zero whole-session rotations are used (deterministic, no RNG, N-1 >= 300
    satisfied with margin). Every rotation preserves the contiguous label-block
    structure and within-era serial dependence; one shared shift set serves S, L1
    and |dShare| (dependence-preserving family null per CLAUDE.md §4).
    p95 = numpy percentile(95, linear) of null S; BREAK iff S_real > p95.
    Achieved p reported as (1 + #{S_k >= S_real}) / (1 + n_shifts).
