=== 4b. SUPPORT SIZE - a circular block bootstrap with nb blocks over n starts has n^nb
===     distinct paths. Where that is small, the 'distribution' is a FINITE SET OF ATOMS
===     and a percentile of it is QUANTIZED, not merely noisy. More replicates cannot help.
========================================================================================================

    A     12   3       4     2,058,346,161   600,000   ample

    A     12  12       1               213   600,000   DEGENERATE - enumerable, see below
    B     25   3       9902,436,039,641,232,310,272   600,000   ample
    B     25   6       5   438,427,732,293   600,000   ample
    B     25  12       3         9,663,597   600,000   ample
    C     50   3      173,823,431,012,410,102,084,423,135,744,875,147,821,056   600,000   ample
    C     50   6       9902,436,039,641,232,310,272   600,000   ample
    C     50  12       5   438,427,732,293   600,000   ample

    Where the support is enumerable the EXACT percentile is computable with ZERO Monte-Carlo
    error, so it is reported exactly rather than sampled:
      A L=6: EXACT p01 $ -14,792.61   sampled $ -14,805.01   error $   -12.40   (45,369 atoms)
      A L=12: EXACT p01 $ -11,926.91   sampled $ -11,936.22   error $    -9.31   (213 atoms)

    >>> This is why CPA/L=12 showed a $961 MC sd on p05 in section 2 while its p25 sd was
    >>> only $48: the tail percentile is hopping between ADJACENT ATOMS of a 213-point
    >>> discrete distribution. That is a property of the DESIGN, not of the data, and it
    >>> means L=12 at a 12-week checkpoint is not a bootstrap at all - it is an enumeration
    >>> of the 213 twelve-week windows in the record. It is reported, not silently kept.
