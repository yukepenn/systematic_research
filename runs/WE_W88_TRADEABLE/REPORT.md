## 5. `CORRECTION` recorded against myself

Read 1 of this wave scored every integer split at **ALL-THREE 0 %** and I nearly reported the
object as untradeable. The cause: the corrected gate's drawdown leg compares **raw** drawdowns and
therefore **requires matched nominal exposure** — which the spec says in the definition of the leg
— and I fed it baskets running 2–5 contracts against P1's 1. Same class of error as the gate
defect itself: comparing quantities that are not on the same scale. Fixed by normalising, and the
uncorrected numbers are void.
