R04 RETURN DEFINITION. r(s->s+1) = close(s+1)/close(s) - 1 (simple), valid iff s and

    drop set. P&L compounds log1p(simple portfolio return).

R05 RV OBJECTS (one definition serves both cards, keeping MC-51/MC-38 separable but
    coherent). For session s from 1-min closes, within-session log-return diffs only:
      RV(s)    = sum of squared 1-min log returns over the FULL session;
      RS-(s)   = the same sum restricted to negative returns (Patton-Sheppard);
      RS+(s)   = RV(s) - RS-(s);
      ON_RV(s) = the sum restricted to bars stamped in the overnight segment
                 (tod > 17:00 or tod <= 09:30 — the 18:00->09:30 portion, per card);
      ON_ret(s)= log(close of last bar stamped <=09:30 of s / close(s-1)); valid only
                 for consecutive same-substrate sessions with s, s-1 outside R03 drop
                 set and a bar <=09:30 present. ON term entering HAR is ON_ret(s)^2.
    "Plain 21d RV" (BOTH the MC-51 primary sizing input and the MC-38 baseline
    forecast) = trailing mean of RV over the last 21 sessions including s
    (rolling(21).mean, min 21 obs). MC-51 card names "21d realized variance ... from
    owned 1-min"; this is that object, unmodified. Deciles are monotone-invariant to
    the sqrt, so vol-vs-variance is immaterial for sizing; the variance form is used.

R06 EXPANDING-WINDOW DECILE CALIBRATION (the Cederburg clause — the ONLY calibration).
    At row i the decile thresholds q10/q90 are the 0.10/0.90 quantiles (linear
    interpolation) of the sizing input over ALL rows STRICTLY BEFORE i (shift-1
    expanding window), requiring >= 252 prior non-NaN observations. No full-sample
    constant exists anywhere in the harness. Exposure e(i) = 1.5 if input <= q10
    (bottom decile, low vol); 0.5 if input >= q90 (top decile); else 1.0. First usable
    row = first row with valid thresholds AND session label >= 2006-01-01 AND a valid
    next-session return; its DATE IS PRINTED in the gate table (spec critical clause).
    The identical positional rule is applied inside every null draw (recomputed from
    the shifted series — no leaked thresholds).

R07 CAPITAL BASE / GEOMETRIC GROWTH. "1-contract base" is read as a one-contract-
    notional capital base: capital at decision time s = $20 x close(s) (NQ $20/pt).
    Strategy period return = e(s) * r(s->s+1) - cost(s), with cost(s) =
    $33 * |e(s) - e_prev| / (20 * close(s)) — $33/RT charged on EVERY rebalance
    contract, conservatively counting each contract of size change as a full RT, and
    charging the initial entry (e_prev = 0 at the first scored row). Log-wealth =
    cumulative sum of log1p(period return). No dollar capital constant is invented;
    growth is scale-free. This is the no-leverage-masquerade formulation: exposure
    multiplies the SAME base as the control's.

R08 MATCHED-EXPOSURE CONTROL (V1, enforced IN the gate table). Control exposure

    entry ($33 * e_bar at the first scored row) and NO rebalance costs thereafter
    (constant exposure) — an advantage given to the control, conservative for V1.
    The gate table prints strategy mean |exposure| and control exposure side by side;
    equality is the enforcement.
