R3  The pairing null (shared machinery for all claims). Per-session LEVEL OBJECT = every level the
    claim consumes, expressed as OFFSETS from that session's own RTH open:
      CL1  dONH(s)=ON_high(s)-open(s), dONL(s)=ON_low(s)-open(s)            [own overnight]
      CL2  dVAH(s)=VAH(prior(s))-open(s), dVAL likewise                      [prior-RTH profile]
      CL3  dIBH(s)=IB_high(s)-open(s), dIBL likewise                         [own first RTH hour]
      CL4  dPDH(s)=RTH_high(prior(s))-open(s), dPDL likewise                 [prior RTH extremes]
      CL5/CL6  dVWAP(s,t)=VWAP(s,t)-open(s) per RTH slot t                   [own session VWAP]
    Replication k pairs the UNSHIFTED path of session i (row i's bars, untouched) with the level
    object of session j=(i+k) mod N, re-anchored: LEVEL*(i)=open(i)+d*(j). This is a circular shift
    of the level set across sessions, whole-session unit (each session's level object travels
    intact), leaves every path bar unshifted, preserves level geometry (each offset object is a real
    one, incl. the real prior-session pairing inside dVAH/dPDH) and path dynamics, and destroys
    level-path attraction — exactly the spec's construction. k=0 is the real alignment.
    >=300 shifts: 300 distinct k drawn without replacement from 1..N-1, numpy default_rng(seed=0)
    (null_guard convention). ONE shared k per replication feeds ALL claims (family doctrine).
    Null-sensitivity is verified FIRST (null_guard doctrine): probe shifts [1,7,61]; any claim whose
    statistic has zero spread across probes => DEFECT stop, no percentile quoted.
    The one wrap-seam pair per replication (last session's levels internally referencing the list
    edge) is inherent to any circular construction and affects <=1 of ~1,15x sessions.
R4  Per-claim statistics (all session-level; cluster unit = session, so the clustered CI is the
    plain across-session normal CI, +-1.96*SE; proportions use SE=sqrt(p(1-p)/n)).
    CL1  denominator: sessions with >=1 ON bar and >=1 RTH bar (level session j must have a valid

    CL2  Profile of the prior RTH session: bins of 1.25 pts anchored at absolute multiples of 1.25
         (floor(price/1.25)); each 1-min bar's volume spread across bins proportionally to the
         price-overlap of [low,high] with each bin (low==high => all volume to that bin).
         POC = max-volume bin (tie -> bin closer to the profile's volume-weighted mean price; then
         lower). VA = greedy one-bin expansion from POC: repeatedly add the adjacent bin (above vs
         below the current span, within the profile's occupied range) with more volume (tie ->
         lower) until cumulative >= 70% of total RTH volume. VAL = lower edge of bottom VA bin,
         VAH = upper edge of top VA bin. Event: open(i) strictly outside [VAL*,VAH*] AND first
         trade into the VA (for open above: min_low(i) <= VAH*; symmetric below). Success =
         traversal to the far edge (open above: min_low(i) <= VAL*; symmetric). Because reaching
         the far edge implies having entered at or before that bar, traversal-after-entry ==
         session-extreme reaching the far edge. Stat = conditional traversal share. Direction: ABOVE.
    CL3  IB = bars stamped [09:31,10:30]; post-IB = bars stamped [10:31,16:00]; denominator:
         sessions with >=1 IB bar (level session) and >=1 post-IB bar (path session).

         (b) among extended sessions: first-break direction = whichever level is strictly breached

    CL6  Condition at 09:59: the 09:59-stamped bar exists and |close(i,0959)-VWAP*(i,0959)| >= 20.0
